# Security Policy

## Supported versions

Security fixes are provided for the latest stable release of Beszel API for
Home Assistant. Before reporting a problem, confirm that both this integration
and your Beszel Hub are current.

## Reporting a vulnerability

Please do not publish credentials, tokens, private URLs, full diagnostic dumps,
or exploit details in a public issue.

Use GitHub's private vulnerability reporting for this repository when the
option is available. If it is not available, open a minimal public issue asking
the maintainer for a private contact channel. Include no sensitive technical
details in that issue.

In a private report, please include:

- the affected integration, Home Assistant, Beszel Hub, and Agent versions;
- the security impact and the conditions required to reproduce it;
- minimal reproduction steps or a proof of concept;
- any suggested mitigation, if known.

Reports concerning the Beszel Hub or Agent rather than this Home Assistant
integration should be submitted to the
[Beszel project](https://github.com/henrygd/beszel/security).
